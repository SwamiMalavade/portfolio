# Swami Malavade — Portfolio

Personal portfolio website built with React, Material UI, and Framer Motion.

## Tech Stack

- **React 19** with Vite
- **Material UI (MUI) v7** for components and theming
- **Framer Motion** for animations
- **react-scroll** for smooth in-page navigation

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
